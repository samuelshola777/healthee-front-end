# Artwork and typography

The selected design is preserved in `design-reference/selected-design.png`. The site is real HTML, CSS and TypeScript; headings, navigation, controls and feature-card copy remain editable.

Both hero MP4 files and their responsive poster images are retained from the existing project. The animation's original bottle placement and frames differ from the static concept image. CSS positions the video below the centred headline without rewriting the video.

The reference did not include editable artwork or the original display-font file. Fraunces 900 with soft forms approximates its rounded display typography; Poppins is used for body text. Both are bundled locally with their SIL Open Font Licenses. The header wordmark is recreated in live typography with a small SVG leaf, not an original logo master.

The five PNGs in `public/assets/fresh-market/` were recreated from the selected reference using the built-in image-generation tool. Transparent artwork keeps the page editable and avoids embedding the mockup as the website. These are close visual recreations, not identical extracted source photographs. Existing bottle images in product dialogs are illustrative assets from the previous project. Copy on the page follows the supplied mockup.

Match reference photo-real art and proportions closely. Isolate just these objects on TRUE TRANSPARENT background.

### ingredients

Use case: background-extraction. Reference is selected website. Produce a production-ready transparent ingredient sprite strip for the five flavour dock. ONE single horizontal row of exactly FIVE separate photorealistic miniatures at evenly spaced positions 10%,30%,50%,70%,90% of image width, each fully contained in its own equal fifth of the canvas with generous gaps: 1 orange half facing viewer, 2 triangular watermelon wedge upright, 3 small pineapple with green crown and yellow pineapple wedge in front, 4 one dark red hibiscus flower, 5 two round brown tigernuts and a white coconut half. Match these exact dock objects in reference. Make strip wide 3:1 aspect ratio, objects equal visual size. All objects isolated on a true transparent background; no shadows behind, no text, no captions, no cream rectangles, no borders, no UI. Every object centered within its own equal fifth of width; full artwork stays within centre 80% height.
